# SE-project-summer2026
As a student, it's easy to lose track of assignment deadlines when you're juggling multiple classes, projects, and exams. This project was created to make staying organized a little easier by keeping important due dates visible at all times. The application automatically reads assignment deadlines, calculates how much time is left, and displays a small countdown timer in the corner of the screen so you always know what needs your attention next. Instead of opening Brightspace or checking a planner throughout the day, you can simply glance at the timer to see how much time remains before your next assignment is due. The goal is to create a simple, distraction-free tool that helps students manage their time, avoid last-minute stress, and build better study habits without getting in the way of their daily workflow.
